# FormCoach

iPhone Home Screen gym coach. Your camera tracks form. AirPlay the screen to the TV.

## Open on iPhone

https://kdds.github.io/formcoach/

1. Open that link in **Safari**
2. Share → Add to Home Screen
3. Open the FormCoach icon, allow camera
4. Control Center → Screen Mirroring → TV / Apple TV
5. Prop the phone so the camera still sees you

No computer. No account.

A native App Store app cannot be installed from chat. That needs a Mac and an Apple Developer account.
